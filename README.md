# NEXORA DIGITAL PLATFORM

A full-stack business website and DevOps learning project.

## Technologies

- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- PostgreSQL
- Maven
- Git
- GitHub
- Docker
- Docker Compose
- Jenkins
- Terraform
- Prometheus
- Grafana

## Application

NEXORA is a digital solutions business platform.

Customers can explore services, projects and pricing
and submit enquiries.

## Backend

Spring Boot handles API requests.

## Database

PostgreSQL stores customer enquiries.

## Containers

Docker packages the application.

Docker Compose manages the application and database.

## CI/CD

Jenkins automates testing and image building.

## Monitoring

Prometheus collects application metrics.

Grafana visualises monitoring information.
